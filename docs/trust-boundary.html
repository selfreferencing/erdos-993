Lean Is The Check

AI output is not trusted as mathematics. The release target is checked Lean code plus a reviewable explanation of generated finite certificate data and the bridge that connects it to actual mathematical objects.

Generated Data Boundary

Generated tables may recognize already-classified keys. They may not be used to prove the actual classification of a selected package. The dependency direction is actual geometry first, generated recognition second.
