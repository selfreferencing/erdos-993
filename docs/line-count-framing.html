Line-count framing

No inflated headline number

The project contains a large generated/certificate layer. It should not be described as millions of lines of human-written proof. The honest framing is a compact public theorem wrapper, a human-readable semantic proof architecture, a large generated finite certificate layer, and explicit scripts and reviewer guides for checking the boundary.
