Project brief

Erdős 993 Formalization

An AI-assisted Lean proof program for unimodality of independent-set sequences of finite trees, organized around a public finite-acyclic graph theorem and a large semantic/certificate bridge.

Public Mathematical Claim

∀ {Vtx : Type} [Fintype Vtx] [DecidableEq Vtx]
  (G : SimpleGraph Vtx) [DecidableRel G.Adj],
    G.IsAcyclic →
      Unimodal (independenceSequenceOfGraph G)

Current State

The public theorem wrapper and source-free final theorem files are prepared in the private technical repository. The remaining active frontier is P116: the semantic actualization bridge connecting selected package certificates to the public theorem chain.

Why The Repository Is Large

The project separates ordinary Lean proof code, generated finite certificates, computational audits, and AI prompt/result records. The public communication goal is to make those layers visible rather than presenting all files as one undifferentiated proof.
